## Setup in under 5 minutes

Follow these steps to install Mintlify and start building your documentation site.

### Step 1: Install Mintlify CLI

Install the Mintlify command line tool globally using npm:

```bash
npm i -g mint
```

<Note>Requires Node.js 18 or higher. Check your version with `node -v`.</Note>

### Step 2: Clone your docs repository

Clone your documentation repository to your local machine:

```bash
git clone https://github.com/your-org/your-docs
cd your-docs
```

Find your repository URL in your [Mintlify dashboard](https://dashboard.mintlify.com).

### Step 3: Start the development server

Run the local preview server to see your docs:

```bash
mint dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser. Your changes will hot-reload as you edit files.

### Step 4: Make your first edit

Try updating your site's name and colors:

1. Open `docs.json` in your editor
2. Update the `name` field to your project name
3. Modify the `colors` to match your brand
4. Save and see changes instantly in your browser

```json docs.json
{
  "name": "Your Product Name",
  "colors": {
    "primary": "#16A34A",
    "light": "#07C983",
    "dark": "#15803D"
  }
}
```

### Step 5: Deploy to production

Push your changes to deploy:

```bash
git add .
git commit -m "Update documentation"
git push
```

Your site will be live in moments via the [Mintlify GitHub app](https://dashboard.mintlify.com/settings/organization/github-app).
