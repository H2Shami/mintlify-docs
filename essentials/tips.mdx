## Keep it simple

Write for your reader, not yourself. Use short sentences and plain language.

## Use examples

A good code example is worth a thousand words of explanation.

```javascript
// Bad: vague description
// "Call the function with the right parameters"

// Good: concrete example
const response = await fetch("/api/users", {
  method: "POST",
  body: JSON.stringify({ name: "Jane", role: "admin" }),
});
```

## Structure your pages

- Start with a clear title and description
- Use headings to break up content
- Put the most important information first
- End with next steps or related links

## Add visuals

Use screenshots, diagrams, and code blocks to break up walls of text. Readers scan before they read.
